⏻ 开机自启动

Windows 登录后使用 pythonw.exe 静默启动系统托盘与本地服务，不显示命令行窗口，也不会主动打开浏览器。

默认关闭。仅操作当前用户的启动项，无需管理员权限；关闭开关不会停止当前服务。手动静默启动可双击 start_silent.pyw；右键系统托盘图标可以重启或退出服务。升级旧版自启动请关闭开关后重新开启；调试时使用 start_windows.bat。

全局快捷键只保留一个：右键托盘图标 →「设置全局快捷键」，选择合适的组合。按键会打开功能菜单，可选择快速收藏、文件夹、工作区或主界面。

⌂ 设为浏览器启动页

先开启开机自启动，再将以下地址设置为浏览器“启动时打开的页面”。

http://127.0.0.1:8765/

打开文件夹后会尝试把资源管理器窗口提升到浏览器前方，但 Windows 焦点保护机制可能限制这一操作。

Chrome：设置 → 启动时 → 打开特定网页；Edge：设置 → 开始、主页和新建标签页。初次登录时若显示无法连接，稍后刷新页面即可。

🧭 智能迁移建议

换盘符或换电脑后，填写已存在的新项目根目录。仅对已收藏的导航路径尝试推断旧目录前缀，不递归搜索磁盘，也不会自动更改数据库。

输入新根目录后手动生成建议；较慢的网络共享目录可能延长检查时间。

建议依赖新目录中实际可访问的少量路径样本，不保证所有子目录都存在；点击「采用并生成预览」仍须核对全部模块，再手动确认。请先下载完整 ZIP 备份。
