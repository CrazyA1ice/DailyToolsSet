⏻ 开机自启动

Windows 登录后使用 pythonw.exe 静默启动，不显示命令行窗口，也不会主动打开浏览器。

默认关闭。仅操作当前用户的启动项，无需管理员权限；关闭开关不会停止当前服务。手动静默启动可双击 start_silent.pyw；如需查看错误则使用 start_windows.bat。

⌂ 设为浏览器启动页

先开启开机自启动，再将以下地址设置为浏览器“启动时打开的页面”。

http://127.0.0.1:8765/

打开文件夹后会尝试把资源管理器窗口提升到浏览器前方，但 Windows 焦点保护机制可能限制这一操作。

Chrome：设置 → 启动时 → 打开特定网页；Edge：设置 → 开始、主页和新建标签页。初次登录时若显示无法连接，稍后刷新页面即可。

📦 本地数据健康状态

只检查 FolderHub 运行数据，不扫描你绑定的真实文件夹。

选择「数据与备份」后开始检查。

完整备份包含 data/folderhub.db、data/preferences.json 和正在使用及回收站引用的封面图片。

界面字号、主题、封面显示、侧栏展开和网格/列表布局现保存在项目 data/preferences.json，不再依赖浏览器缓存。下载文件请妥善保存在项目目录之外。它包含你的本机路径、模块、封面和回收站内容，不要上传到公开 GitHub。恢复前需退出 FolderHub 并备份当前 data/、uploads/，再解压覆盖。
