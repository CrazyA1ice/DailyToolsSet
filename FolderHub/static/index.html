⏻ 开机自启动

Windows 登录后在后台静默启动本地服务，不主动弹出浏览器。

仅操作当前用户的启动项，无需管理员权限。关闭开关仅影响下次登录，不会停止当前服务。

⌂ 设为浏览器启动页

先开启开机自启动，再将以下地址设置为浏览器“启动时打开的页面”。

http://127.0.0.1:8765/

Chrome：设置 → 启动时 → 打开特定网页；Edge：设置 → 开始、主页和新建标签页。初次登录时若显示无法连接，稍后刷新页面即可。
